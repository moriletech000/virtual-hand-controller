================================================================================
  GITHUB REPOSITORY SETUP INSTRUCTIONS
================================================================================

This guide will help you create a new GitHub repository and push your code.

================================================================================
  OPTION 1: AUTOMATED SETUP (RECOMMENDED)
================================================================================

Windows Users:
--------------
1. Double-click: setup_github.bat
2. Follow the prompts
3. Go to https://github.com/new and create the repository
4. Run: git push -u origin main

Linux/Mac Users:
----------------
1. Run: chmod +x setup_github.sh
2. Run: ./setup_github.sh
3. Follow the prompts
4. Go to https://github.com/new and create the repository
5. Run: git push -u origin main

================================================================================
  OPTION 2: MANUAL SETUP
================================================================================

Step 1: Prepare the README
---------------------------
Copy README_PUBLIC.md to README.md:

Windows:
  copy README_PUBLIC.md README.md

Linux/Mac:
  cp README_PUBLIC.md README.md


Step 2: Initialize Git Repository
----------------------------------
git init
git add .
git commit -m "Initial commit: Virtual Hand Controller"


Step 3: Create GitHub Repository
---------------------------------
1. Go to: https://github.com/new
2. Repository name: virtual-hand-controller (or your choice)
3. Description: Control your computer with hand gestures
4. Make it PUBLIC
5. Do NOT check:
   - Add a README file
   - Add .gitignore
   - Choose a license
6. Click "Create repository"


Step 4: Push to GitHub
-----------------------
Replace YOUR_USERNAME with your GitHub username:

git remote add origin https://github.com/YOUR_USERNAME/virtual-hand-controller.git
git branch -M main
git push -u origin main


Step 5: Verify
--------------
Go to: https://github.com/YOUR_USERNAME/virtual-hand-controller
You should see all your files!

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: "git: command not found"
Solution: Install Git from https://git-scm.com/downloads

Problem: "remote origin already exists"
Solution: Run: git remote remove origin
         Then try again

Problem: "failed to push"
Solution: Make sure you created the repository on GitHub first
         Make sure the repository name matches

Problem: "authentication failed"
Solution: Use a Personal Access Token instead of password
         Generate at: https://github.com/settings/tokens
